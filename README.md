# Вишлист Павлика

Мой список подарков — одна ссылка для всех.

**Ссылка:** https://puik1.github.io/wishlist/

## Как этим пользоваться

- **Друзьям:** открыть ссылку, нажать на карточку — она перевернётся и покажет магазин.
  Можно отметить подарок кнопкой «Я это подарю», чтобы не подарили одно и то же.
- **Мне:** трижды нажать на заголовок, ввести секрет и войти — откроется правка.

## Что внутри

Список хранится в Supabase, поэтому правки видны всем сразу. Фотографии — на Ozon.
